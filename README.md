# Machine Learning supervisé : cours, TP et projets

Travaux d'apprentissage automatique réalisés pendant le Master Data & IA : des fondamentaux de la régression jusqu'à un projet de classification en santé.

## Contenu

| Dossier | Description |
|---|---|
| `Intro_ML/` | Introduction : régression linéaire, classification, clustering K-Means |
| `Analyse du Risque Cardiovasculaire/` | Projet : prédiction du risque de maladie coronarienne à 10 ans par **régression logistique** (exploration, corrélations, évaluation) |
| `Machine Learning NEXA/Notebook/` | Cours et TP : régression linéaire simple et multiple, descente de gradient, Ridge / Lasso / ElasticNet, métriques, validation croisée, diagnostic de l'overfitting, analyse des résidus |
| `Machine Learning NEXA/Cours/` | Supports de cours (évaluation, régularisation, arbres de décision, entropie croisée) |

## Compétences illustrées

- Poser un problème de régression ou de classification et choisir ses métriques.
- Éviter les pièges classiques : fuite de données, overfitting, R² trompeur.
- Régulariser, valider par validation croisée, analyser les résidus.

## Outils

Python, pandas, NumPy, scikit-learn, SciPy, Matplotlib, Seaborn.
